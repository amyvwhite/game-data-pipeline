# AWS data lake setup (one time, ~10 minutes)

Everything is defined in `infra/aws/stack.yml` (generated by `infra/aws/build_template.py`).
Design and costs: [ADR 0005](adr/0005-aws-data-lake.md).

1. **Create the stack.** AWS console → CloudFormation → *Create stack* → *Upload a template
   file* → `infra/aws/stack.yml`. Stack name `game-data-lake`. Set `BudgetEmail`; keep the
   other defaults (set `CreateOIDCProvider` to `false` only if the account already trusts
   GitHub's OIDC provider). Acknowledge IAM resources → *Submit*.
2. **Confirm the budget email** AWS sends, so cost alerts are delivered.
3. **Copy two outputs** from the stack's *Outputs* tab into GitHub → repo *Settings* →
   *Secrets and variables* → *Actions* → **Variables** (not secrets; neither is a credential):
   - `AWS_ROLE_ARN` = `RoleArn`
   - `S3_BUCKET` = `BucketName`
   - `AWS_REGION` = the stack's region (e.g. `us-east-2`)
4. **Run the live workflow.** The "Export missing days to the data lake" step uploads every
   complete day so far and checks it with an Athena query.
5. **Query it.** Athena console → workgroup `game-data` → database `game_data`. Three saved
   queries are included (Take-Two share by day, Steam top 10, review themes).

To remove everything: delete the stack. The bucket is kept on purpose (`DeletionPolicy:
Retain`) so data is never lost by accident; empty and delete it by hand if you want it gone.
